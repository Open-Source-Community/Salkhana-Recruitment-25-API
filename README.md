# Salkhana Recruitment Interview Studio

Create interview question packs for Level 1 (Foundations) or Level 2 (Development). Packs are saved as Markdown files in `markdowns/`.

## Question packs

Choose random questions or select them manually. Both modes follow the topic requirements configured for the selected level.

- **Level 1:** 20 questions — 7 Beginner, 8 Intermediate, and 5 Advanced.
- **Level 2:** 20 questions — 7 Beginner, 9 Intermediate, and 4 Advanced.

Question numbers in the generated Markdown match their IDs in the question bank.

## Run the app

1. Install dependencies: `npm install`
2. Start the server: `npm run dev`
3. Open `http://localhost:3001`

Question banks are in `questions_data/Level_1/questions.json` and `questions_data/Level_2/questions.json`.
